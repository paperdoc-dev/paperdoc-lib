## How to be listed here

Open a pull request that gets merged into `main`. After merge, we add you to this file in the next release — no action required on your part, but feel free to submit a PR if we miss you.

Every contribution is welcome: code, tests, documentation, bug reports. See [`CONTRIBUTING.md`](CONTRIBUTING.md) for details.
